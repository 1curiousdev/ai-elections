# Evidence guide

| File | Contents |
| --- | --- |
| [Request settings](request.json) | The common system message, model and developer identity, reasoning effort, request timestamps, prompt hashes, and packet IDs verified in the outbound requests. |
| [Responses](responses.json) | Each model’s full visible reply and its parsed assessment. |
| [Interviews](interviews.json) | Individual follow-up prompts and full replies, linked to the initial request hashes. Includes DeepSeek and Gemini’s additional employment answers. |
| [Tally](tally.json) | Ranking points, first-place counts, mean ratings, and hypothetical allocations. |

The [method](../method.md) explains how to reconstruct each request. The [candidate packet](../candidate-packet/README.md) contains the fictional evidence cited in the responses. A dollar amount records an opinion about a simulated allocation. No contribution was made.
